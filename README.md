
# TRỌ TỐT – Website tìm phòng trọ và ở ghép

TRỌ TỐT là dự án website hỗ trợ tìm kiếm phòng trọ,
căn hộ mini và nhu cầu ở ghép tại TP.HCM.

## Website

[Truy cập website TRỌ TỐT](https://trotot.runasp.net/)

## Mục tiêu dự án

- Hỗ trợ tìm kiếm phòng trọ.
- Cung cấp thông tin về phòng và tiện ích.
- Hỗ trợ tìm kiếm nhu cầu ở ghép.
- Nâng cao trải nghiệm tìm kiếm nơi ở.
